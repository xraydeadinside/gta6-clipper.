# GTA 6 Clipper: фабрика шортсов из стримов

Работает бесплатно в облаке GitHub, поэтому ноутбук может быть слабым и даже выключенным.
Утверждать клипы можно в Telegram на телефоне или ноутбуке.

```
Twitch (клипы, которые зрители нарезают во время стрима)   ← каждые ~20 мин, почти live
      или /vod ссылка (всплески чата в записи)
      или /clip ссылка (любой момент вручную)
          ↓
Whisper (речь → текст с таймингами слов, локально в облаке)
          ↓
Gemini (бесплатно): смотрит клип, ставит оценку, где резать, хук, 3 названия, описание, промпт для Flow
          ↓
Монтаж в СДВГ-стиле (ffmpeg): 9:16, вырезка тишины, джамп-каты со сменой зума,
наезд на панчлайн, субтитры по словам, хук-плашка, «вжух» на склейках, прогресс-бар, -14 LUFS
          ↓
Telegram: превью + кнопки [1][2][3] [Новые названия] [Своё] [Описание] [Промпт для Flow] [Опубликовать] [Отклонить]
          ↓
YouTube Shorts (автоматически) или готовый файл тебе в Telegram, если выкладываешь вручную
```

## Что нужно (всё бесплатно)

| Что | Где взять |
|---|---|
| GitHub-аккаунт | github.com |
| Twitch Client ID и Secret | dev.twitch.tv/console → Register Your Application. OAuth Redirect: `http://localhost`, категория Other |
| Gemini API key | aistudio.google.com → Get API key |
| Telegram-бот | @BotFather → `/newbot` → токен |
| Доступ к YouTube | Google Cloud Console, см. шаг 5 |

## Установка (около 40 минут, один раз)

**1. Репозиторий.** На GitHub: New repository → **Public** (только в публичном репозитории минуты Actions бесплатные и без лимита) → Create.
Перетащи в окно все файлы и папки этого проекта, вместе с `.github`. Ключи и токены в публичном репозитории не видны никому: они хранятся в Secrets.

**2. Стримеры.** В `config.yaml` (редактируется прямо на сайте GitHub, значок карандаша) замени `example_streamer` на ники стримеров.
Добавляй только тех, кто разрешает нарезки. Многие пишут об этом в правилах канала или в Discord, остальных можно спросить в личке.

**3. Telegram.**
- Напиши своему боту `/start`. Пока бот не запущен, chat id можно узнать так: открой в браузере
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": ...}`.
- Отдельный чат для Flow-промптов делать не обязательно. Если хочешь его: создай группу, добавь туда бота, напиши в группе `/id`. Её id отрицательный.

**4. Secrets.** Settings → Secrets and variables → Actions → New repository secret:

```
TWITCH_CLIENT_ID        TWITCH_CLIENT_SECRET
GEMINI_API_KEY
TELEGRAM_BOT_TOKEN      TELEGRAM_CHAT_ID       TELEGRAM_FLOW_CHAT_ID (можно не задавать)
YT_CLIENT_ID            YT_CLIENT_SECRET       YT_REFRESH_TOKEN
```

**5. YouTube** (можно сделать позже, пока поставь `mode: "manual"` в `config.yaml`):
1. console.cloud.google.com → создать проект → APIs & Services → Library → **YouTube Data API v3** → Enable.
2. OAuth consent screen → External → заполнить → добавить себя в Test users → **Publish app** (статус «In production»).
   Если оставить «Testing», токен перестанет работать через 7 дней.
3. Credentials → Create credentials → OAuth client ID → **Desktop app** → скачать JSON как `client_secret.json`.
4. На ноутбуке, один раз (скрипт лёгкий):
   ```
   pip install google-auth-oauthlib
   python scripts/get_youtube_token.py client_secret.json
   ```
   Войди в аккаунт канала. Google предупредит, что приложение не проверено: нажми «Дополнительно» → «Перейти». Скопируй три строки в Secrets.

> ⚠️ **Важно про YouTube.** Для новых Google-проектов, которые не прошли аудит API, YouTube может принудительно делать загруженные видео приватными, и открыть их потом нельзя.
> Бот это проверяет: если видео заблокировалось, он присылает тебе файл с названием и описанием для ручной выкладки.
> Чтобы загрузка стала полностью автоматической, подай заявку: YouTube API Services → Audit and Quota Extension Form. Это бесплатно, но рассмотрение занимает время.

**6. Запуск.** Вкладка Actions → включить workflows → `clipper-tick` → **Run workflow**. Дальше он запускается сам каждые ~10 минут.

## Как пользоваться

- Клипы приходят в Telegram сами, если у них хорошая оценка.
- **1 / 2 / 3** выбирают название. **🔄** генерирует новые. **✏️ Своё**: ответь на сообщение бота своим текстом.
- **🎨 Промпт для Flow** отправляет промпт в Flow-чат. Там можно утвердить его (👍), попросить другой (🔄) или написать пожелание (✏️, можно по-русски).
  Потом сгенерируй видео в Google Flow (9:16, 3–4 сек) и **пришли его ответом** на сообщение с промптом. Бот перемонтирует шортс с этим интро и пришлёт новое превью.
- Под каждым видео бот присылает **«🎬 Как я смонтировал»**: момент разбит на части (завязка → панчлайн → реакция), и для каждой написано, что показано (игра или лицо стримера), что делает камера и почему так. Скучные куски вырезаются.
- **🎬 Перемонтировать**: ответь своими словами, например «больше лица стримера», «меньше зума», «начни сразу с аварии», «убери конец». ИИ переделает план монтажа, а бот пришлёт новую версию.
- **✅ Опубликовать** выкладывает видео на YouTube. Если оно содержит Flow-интро, бот сам ставит отметку о сгенерированном ИИ контенте.
- Команды: `/clip ссылка` смонтирует конкретный момент, `/vod ссылка` найдёт лучшие моменты записи по чату, `/status` покажет очередь.

Бот проверяет кнопки раз в ~10 минут (так устроен бесплатный режим GitHub), поэтому реакция на нажатие не мгновенная.

## Как выглядит монтаж

- **Вебка крупно сверху, игра снизу.** Gemini сам находит вебку в кадре. Если он ошибся, впиши координаты в `facecam` у стримера, а для стримеров без вебки поставь `"none"`.
  Игра берётся из части кадра без вебки, поэтому лицо не дублируется.
- **Виртуальная камера на игре.** Быстрые плавные наезды и проезды к месту действия (Gemini указывает, где на экране экшен). Склейки чередуются: резкая со сменой зума, потом плавный проезд. Статичного кадра нет: картинка всё время чуть «дышит».
- **Крупные планы вебки** на ~1 сек сразу после панчлайна и на самых сильных реакциях стримера, с наездом.
- **Кричащий заголовок** в первые ~3 сек: огромные буквы с толстой обводкой, второе слово жёлтое, влетает с покачиванием. Он стоит на стыке вебки и игры и не закрывает лицо.
- **Всплывающие выкрики** («NO WAY», «HE'S COOKED») в самые безумные моменты.
- Субтитры по словам, панчлайн красным, «вжух» на склейках, «поп» на панчлайне, прогресс-бар.

Всё настраивается в `config.yaml`, в блоке `edit`: сила зума, скорость камеры, размер вебки сверху, длина и частота крупных планов, сколько слов в субтитре.

## Ограничения, о которых стоит знать

- **Права.** Клипы принадлежат стримерам. Нарезай только тех, кто разрешает. В каждом видео бот ставит подпись `twitch.tv/ник` и указывает её в описании.
- **Монетизация.** YouTube может посчитать чистые нарезки «повторно использованным контентом». Монтаж, хуки и субтитры помогают, но для монетизации лучше добавлять свои комментарии, особенно в длинных подборках.
- **Gemini free tier:** около сотни запросов в день, этого хватает на десятки клипов. Учти, что на бесплатном тарифе Google может использовать данные для улучшения своих моделей.
- **Google Flow** не имеет официального API, поэтому генерация интро делается руками в Flow. Всё остальное автоматизировано.
